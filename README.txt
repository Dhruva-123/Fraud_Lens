This repo consists of my attempt at creating an end-to-end ML pipeline that ingests data, processes it, trains on it, and give us a prediction engine to predict if a given transaction is fraudulent or not in a fintech environment.


In this repository, we explore both unsupervised and supervised learning approaches to detect fraudulent transactions. The goal is to evaluate which type of model performs better on this highly imbalanced dataset and to understand the strengths and limitations of each approach in identifying rare fraud patterns.
