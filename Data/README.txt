The data we used for this project is obtained from Janio Martinez Bachmann's Kaggle publication. Here is the link if you are interested to take a look:

https://www.kaggle.com/code/janiobachmann/credit-fraud-dealing-with-imbalanced-datasets/notebook

All rights to the original dataset belong to the respective author(s) and Kaggle. The dataset has been used here strictly for educational and research purposes.

Dataset Overview
- Rows: 284,807  
- Features: 31 (including Time, Amount, Class and V1–V28)  
- Target: Class (1 = Fraud, 0 = Non-Fraud)  
- Notes: The features V1–V28 are anonymized using PCA to protect sensitive information.

We have the Non-Compressed file for our actions and the compressed file for anyone wanting to use the data from scratch.
