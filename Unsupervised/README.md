Our dataset consists of PCA-generated features (V1–V28) along with Amount, Time, and Class. The correlation analysis shows that these components do not exhibit meaningful linear relationships with each other, implying that each feature contributes independently to the representation of a transaction. Since the dataset is already PCA-compressed, additional dimensionality reduction is unnecessary.

Even though the data contains labels (Class = 0/1), we apply unsupervised learning to evaluate how well fraud patterns naturally separate from non-fraud patterns without supervision. This mirrors real-world situations where labels are sparse, unreliable, or entirely missing.

Looking at the unsupervised models, none of them perform well on this extremely imbalanced dataset. OCSVM completely failed, predicting almost all transactions as non-fraud (class 0), showing it cannot capture the tiny minority class. K-Means also failed as expected, producing near-zero scores; it struggles with imbalanced data and requires roughly spherical clusters, which this data does not have. Isolation Forest performed slightly better, achieving a precision of 0.18, recall of 0.37, and F1-score of 0.24, but this is still very low and far from practical. Overall, unsupervised methods are largely ineffective for this type of fraud detection problem, and the data appears better suited to supervised approaches given its near-linear separability.
