Looking at the results, a few clear patterns emerge. XGBoost is the strongest model overall, with the highest PR-AUC (0.8605) and a solid balance between precision (~82%) and recall (~85%) for fraud detection, making it the most reliable at catching true frauds while keeping false positives manageable. SVC performs decently (PR-AUC 0.7129) but lags behind XGBoost in recall and F1, showing it’s less effective at distinguishing subtle patterns in this highly imbalanced data. Logistic Regression is simpler and achieves good recall (~80%) with lower precision (~69%), meaning it catches many frauds but produces more false positives. Naive Bayes struggles here; while recall is fairly high (~77%), precision is extremely low (~9%), resulting in many false alarms, and PR-AUC is very low (0.0841), indicating it fails to separate fraud from non-fraud reliably. Overall, tree-based methods like XGBoost are clearly superior for this type of imbalanced, complex dataset.
